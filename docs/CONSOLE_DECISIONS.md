# Console Development Unit Decisions

Status: Active
Version: 1.0.0
Owner: Curvature Console Development Unit

## CDU-ADR-001 — Console Development Unit approved

Date: 2026-08-04
Status: Accepted

CDU is the authority responsible for Curvature Console development. It is not a Chronicle production department and does not inherit Project, Core or Research authority.

## CDU-ADR-002 — Support Unit identity superseded

Date: 2026-08-04
Status: Accepted

The existing Support Unit chat and diagnostics are migrated into CDU. Existing route, conversation, attachments and downloads remain compatible.

## CDU-ADR-003 — Local, free and open-source first

Date: 2026-08-04
Status: Accepted

Optional paid providers require explicit approval, visible cost and must not be required for normal operation.

## CDU-ADR-004 — Sequential Bridge execution first

Date: 2026-08-04
Status: Accepted

Project, Core, Research and CDU may queue independent requests, but only one Browser Bridge exchange runs at a time until real evidence justifies parallel workers.

## CDU-ADR-005 — Adapter-based tool integration

Date: 2026-08-04
Status: Accepted

New tools integrate through a common adapter, workflow, execution and artifact model rather than one-off UI callbacks.

## CDU-ADR-006 — Explicit operator control

Date: 2026-08-04
Status: Accepted

No silent apply, commit, push, paid action or authority transfer is permitted.
